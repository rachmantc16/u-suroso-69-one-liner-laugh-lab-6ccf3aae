A tiny Node program that writes one funny line of at most 200 characters to `/output/entry.txt`: the excuse a robot vacuum gives after eating a sock. The program holds the line in one place, checks it against the gate (single line, 1–200 characters, not blank), and writes it with no trailing newline.

## Run it

```sh
node main.ts
```
